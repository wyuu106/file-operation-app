# 要件定義

## 1. 概要

バックオフィス担当者向けの
ファイル一括リネームデスクトップアプリケーション。

毎月・毎週発生する定型的なファイル名変更作業を
テンプレートとして保存し、再利用できるようにする。

---

## 2. ペルソナ

主なユーザーはバックオフィス担当者。

例:

- 経理
- 総務
- 人事
- 営業事務

エンジニアではないユーザーを想定する。

そのため、

- CLI
- Shell Script
- ターミナル操作
- プログラミング

をユーザーに要求しない。

---

## 3. 目的

最大の目的は、

「定型的なファイル整理に必要な手動操作を減らすこと」

である。

例えば、

30個のファイルを1つずつリネームする作業を、

1. フォルダ選択
2. テンプレート選択
3. プレビュー確認
4. 実行

程度の操作で完了できる状態を目指す。

---

## 4. MVP

MVPでは以下を実装する。

1. フォルダ選択
2. ファイル一覧取得
3. リネームテンプレート作成
4. テンプレート保存
5. テンプレート一覧表示
6. テンプレート編集
7. テンプレート削除
8. リネームプレビュー
9. 一括リネーム
10. Undo
11. 変更履歴の確認

以下はMVP対象外。

- ユーザーアカウント
- ログイン
- クラウド同期
- 複数ユーザー間のテンプレート共有
- Google Drive連携
- OneDrive連携
- AIによるファイル分類
- ファイル内容解析
- ファイル自動移動
- フォルダ自動分類
- サブディレクトリの再帰的な処理
- ディレクトリのリネーム
- 任意の履歴からのUndo
- Redo

## 6. データ管理

テンプレートと変更履歴はSQLiteへ保存する。

すべてユーザーPC内で完結する。

外部サーバは使用しない。

ユーザーのファイル自体やファイル内容はSQLiteへ保存しない。

---

## 7. 非機能要件

### Privacy

ユーザーのファイルを外部サーバへ送信しない。

### Offline

インターネット接続なしで主要機能を利用できる。

### Safety

既存ファイルを意図せず上書きしない。

ファイル操作では、ユーザーのデータを失わないことを優先する。

### Usability

非エンジニアが説明書を読まなくても
基本操作を理解できるUIを目指す。

CLI、Shell Script、ターミナル操作などの
技術的な知識をユーザーに要求しない。
